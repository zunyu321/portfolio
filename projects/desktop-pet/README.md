# Electron 桌面 3D 桌宠

常驻桌面的 3D 角色：透明置顶小窗口，能换装、做动作、跟人聊天，还会记事。

## 结构

```
Electron 主进程        窗口 / 托盘 / 拖拽 / 缩放 / 记忆抽取
  ├─ preload           只暴露 3 个白名单 IPC
  └─ 渲染进程           three.js 场景 + glTF 角色 + 动作调度
资产                   glb 网格 / 贴图 / 动作 clip / 换装配置
```

主进程负责系统能力，渲染层只关心画面与交互，两层之间用白名单 IPC 通信。

## 实现要点

- **渲染**：three.js 加载 glTF 角色，卡通着色 + 描边；换装走独立的部件挂载，热切换不用重启
- **动作**：动作片段按需加载，用 slerp 插值，播完自动回站姿并带一点呼吸
- **窗口**：透明置顶、拖拽移动、位置记忆，支持 60%–180% 缩放
- **对话**：接 OpenAI 兼容接口（DeepSeek），人设写在配置里；回复按关键词驱动表情动作
- **记忆**：`memory.md` 存长期记忆，每轮对话后另起一次便宜的抽取请求，只留下值得记的内容

## 踩过的坑

- 透明窗口里用 `backdrop-filter` 会导致整块面板不渲染，改用纯色半透明
- 静态配件（头饰、道具）没有骨架和挂点，直接加进场景会停在原点，改为按件配挂点变换
- 打包后的 `resources/app` 是独立副本，改源码不重新打包就不会生效，小改动直接拷文件

## 运行

```powershell
cd apps/desktop
.\node_modules\electron\dist\electron.exe .
```

角色资产来自本地游戏包，仅本地自用，不在仓库内分发。
