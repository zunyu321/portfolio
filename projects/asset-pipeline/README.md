# 游戏资产解包与导出管线

从《洛克王国：世界》的加密 pak 里导出角色、贴图与动画，统一转成 glTF / PNG，供 WebGL（three.js）侧直接使用。

## 用的东西

- C# / .NET 10
- CUE4Parse —— 需要 `whoisnian` 的 `rocom` 分支，主线读不了这个游戏的自定义 AES 变体
- glTF / PNG 输出

## 跑法

```powershell
RocoExport --paks <Paks目录> --aes <64位hex> --out <输出目录>
           [--asset <虚拟路径>]...    # 网格 / 骨架 / 动画 / 贴图
           [--list]                   # 只列对象，不写文件
```

`--aes` 与 pak 路径自行准备，仓库里不放任何游戏资源或密钥。

## 处理链路

1. 解密：挂载 pak，注入 AES Key，按自定义的 ver12 策略与 MLE 容器解析
2. 导网格：骨骼网格 → glb（含骨架与蒙皮）
3. 导动画：动画序列采样 → glTF 动画通道，坐标系转换后与游戏内姿态对照，逐骨骼误差收敛到 2° 以内
4. 导贴图：UE 纹理 → PNG，带 mip / 通道处理好
5. 落盘：按虚拟路径还原目录结构，代码只认 manifest 里的相对路径

## 踩过的坑

- **官方分支读不了**：仓库主线对自定义 AES 变体解析失败，换社区分支才解开
- **动画对不上**：采样频率与坐标系差异导致姿态偏移，写脚本逐骨骼比对后修正
- **无骨架配件**：头饰、道具是静态网格，没有 socket，直接加进场景会停在原点，改为按件配置挂点变换
- **材质叠层缺贴图**：`_OP` 层的贴图包里没有，短期补不回来，标记为已知问题，不再投入
